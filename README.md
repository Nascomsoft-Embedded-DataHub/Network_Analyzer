# Network Analyser

Documentation for the **Nascomsoft Embedded Hub — Data Department** Network Analyser MVP, a network visibility tool for authorized Starlink network administrators.

The product provides actionable visibility into bandwidth consumption, device connections, and network health for authorized, owned networks. It operates strictly on headers and metadata and never inspects payload contents.
